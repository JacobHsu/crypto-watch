# BTCUSDT Investment Checklist — 說明書

> `check.html` 的操作手冊，相當於飛行員使用前閱讀的 Checklist Manual。

---

## 概覽

### 用途
對著 TradingView 圖表，逐一核對技術指標，由系統引導判斷，最終給出投資建議。適合技術分析新手，不需要自行判斷漲跌，只需回答「你看到什麼」。

### 使用流程
```
1. 打開 {symbol}.html        → 執行 Section A (PAGE I)        檢查
2. 打開 o/{symbol}.html?t=4h → 執行 Section B (PAGE II ─ Pane) 檢查
3. 查看底部 FINAL DECISION

?t= 需與本次核對的 TIMEFRAME 一致：?t=1h / ?t=4h / ?t=1d（省略時為 4h）
幣種帶參數的頁面則併用：o/altcoin.html?s=SOL&t=1d
```
每次執行檢查表對應一個**時間框架**（例如 1H）。
若要核對 4H，重置後再跑一遍即可。
適用任意幣種：btc / eth / sol / xrp 等。

> 想讓 Comet 這類 AI 瀏覽器代為核對、直接在對話輸出報告，
> 見 [AI 瀏覽器判讀（Comet 等）](#ai-瀏覽器判讀comet-等)。

### Header 欄位
| 欄位 | 用途 |
|------|------|
| SYMBOL | 點擊可編輯，填入本次核對的幣種（預設 BTC）|
| DATE | 自動帶入當天日期 |
| TIMEFRAME | 本次核對的時間框架：1H / 4H / 1D |

**各頁提供的時間框架不同：**

| 頁面 | 時間框架 | 對應 |
|------|---------|------|
| `{symbol}.html` | 1H · 4H · 1D | Section A |
| `o/{symbol}.html` | 15m · 1H · 4H · 1D（用 `?t=` 切換，預設 4H） | Section B |
| `1/{symbol}.html` | 1H · 1D | 已不在本檢查表中 |
| `m/{symbol}.html` | 1W · 1M · 3M | 指標組合不同，**不適用本檢查表** |

> A 段的 1H / 4H / 1D 都能在 B 段找到對應級別，跑完整的 A + B 沒有限制。
> 只要記得把 B 段的 `?t=` 調成跟 TIMEFRAME 一樣，別拿 4H 的副圖去對 1D 的主圖。

## 互動方式

1. **點擊指標名稱** → 展開引導問題面板
2. **選擇你在圖表看到的狀態** → 可能有追加問題
3. **系統顯示結果** → `▲ BUY` / `─ WAIT` / `▼ SELL`
4. 結果顯示後，指標行右側狀態更新，面板自動收合
5. 點「重新判斷」可重設單項；Section 右上角「重置」可清空整段

### 分數計算
- 每個 Section 底部顯示 BUY / WAIT / SELL 各項統計
- **最終判斷**：BUY ≥ 60% → `▲ BUY`，SELL ≥ 60% → `▼ SELL`，其餘 → `◈ WAIT`
- 一項都還沒核對時顯示 `— NOT CHECKED`，不是 `◈ WAIT`
- 分母只算**已核對**項目，不需填滿；下方另外標示覆蓋率（如 `已核對 19/36（53%）· A 19/19 · B 0/17`）供自行斟酌

### 列印
直接 `Ctrl+P`，互動面板自動隱藏，輸出為乾淨的黑白飛行檢查表格式。

## AI 瀏覽器判讀（Comet 等）

`check.html` 內建一份**判讀指引**，讓 Comet 這類 AI 瀏覽器扮演使用者，
對照圖表逐項核對後在對話中輸出報告 —— 不需要真的去點那 36 個項目。

### 給 Comet 的指令

```
打開 https://jacobhsu.github.io/crypto-watch/check.html，
依頁面裡的判讀指引核對並輸出報告。
```

不需要帶任何網址參數。要換幣種或級別，在對話裡直接講（例如「改看 ETH 4H」），
或先在頁面上點好 TIMEFRAME、改好 SYMBOL 再叫它讀。

### 指引怎麼取得

| 管道 | 說明 |
|------|------|
| 隱形內嵌 | 頁面底部的 `#ai-brief`，用 `clip-path` 視覺隱藏但**仍參與排版**（不是 `display:none`），文字留在 accessibility tree 裡，AI 讀頁面就自動取得 |
| `?ai=1` | 整頁只輸出純文字指引。header 的「🤖 AI 判讀指引（純文字）」連結會帶上目前的 symbol / tf |

指引全文由 `T` 與 `STRUCTURE` **自動展開**，不是另外維護的文件 ——
改任何一項的判斷規則，指引會同步跟著變，不會脫節。

### 幣種與級別如何決定

沒有網址參數時，一律以頁面 header 目前顯示的 SYMBOL / TIMEFRAME 為準（預設 `BTC` / `1H`）。
改動 SYMBOL 或按 TIMEFRAME 按鈕會即時重寫內嵌指引，AI 不會讀到過期的值。

指引裡的圖表頁網址依幣種自動換算：

| 幣種 | Section A | Section B | 2×2 細看頁 |
|------|-----------|-----------|-----------|
| BTC / ETH | `btc.html` | `o/btc.html?t=1h` | `btc/1h.html` |
| 其他幣種 | `altcoin.html?s=SOL` | `o/altcoin.html?s=SOL&t=1d` | 無（只有 `btc/`、`eth/` 有細看頁，會自動省略） |

### 指引內容

1. **角色** — 你是這份檢查表的使用者，逐項確認
2. **硬規則**（6 條）— 防幻覺用，見下
3. **版面對照** — `{symbol}.html` 是 3 列 × 4 欄，第 1 列 = 1H、第 2 列 = 4H、第 3 列 = 1D；各欄實際載入哪些指標
4. **36 項完整決策樹** — 含兩層追問的項目會展開成巢狀

關鍵的防幻覺規則：

```
看不清楚、指標沒顯示、無法確認  → 一律選 WAIT，禁止用市場常識或價格印象推測
每一項都要附「證據」            → 一句話描述圖上的具體空間關係或數值
寫不出具體證據                  → 該項改回 WAIT
```

輸出格式：

```
[編號] 項目名稱 | BUY|WAIT|SELL | 證據：<你在圖上看到什麼>
...
BUY: n · WAIT: n · SELL: n · 已核對 n/36
FINAL: ▲ BUY / ◈ WAIT / ▼ SELL
```

### 判讀準確率的注意事項

TradingView 圖表是**跨域 iframe 裡的 canvas**，DOM 讀不到指標數值，AI 只能靠視覺判讀。
因此：

- `{symbol}.html` 是 12 張圖擠一頁，每張約 300px 寬，判讀難度高
- 指引裡已附上 `{symbol}/{tf}.html`（2×2 大圖）作為替代，圖大很多，準確率較高
- **務必檢查 AI 回報的「證據」欄**。寫得出「綠線最上、紅線居中、藍線最下，K 棒在三線上方」
  這種具體空間關係才可信；只回「趨勢向上」這類空話代表它在猜，該項應視為 WAIT

## Section A — PAGE I（`{symbol}.html`）

對應圖表：`4 欄 × 1H / 4H / 1D`，共 **19 個核對項目**。

每一欄的核對項目 = 該欄圖表實際載入的指標（定義於 `indicators.js`），順序一致：

| 欄位 | 圖表載入的指標 |
|------|---------------|
| COL 1 — TREND | Multi-Time Period · Williams Fractals · Williams Alligator · Parabolic SAR |
| COL 2 — CHANNEL | Bollinger Bands · Keltner Channel · MA Cross · Volatility Stop |
| COL 3 — MOVING AVERAGE | MA 20/50 · EMA 20/50 · Donchian Channels |
| COL 4 — TREND / EXIT | Zig Zag · Supertrend · Linear Regression · VWMA |

（`↳` 開頭的組合判斷項不是獨立指標，是兩個指標的交叉確認。）

> ⚠️ `↳ SAR × LINEAR REG` 是唯一的**跨欄**組合：PSAR 在 COL 1、Linear Regression 在 COL 4，
> 需要同時看兩張圖。其餘組合項的兩個指標都在同一欄。

### COL 1 — TREND（趨勢系統）

#### MULTI-TIME PERIOD（多時間框架）
> 在單一圖表上同時顯示多個時間框架的趨勢方向。

**⚠️ 判斷方式：數色塊的紅綠比例**

```
指標顯示一排色塊，每格 = 一個時間框架（如 1m 5m 15m 1H 4H 1D 1W…）
  🟢 綠色格 = 該時間框架看漲
  🔴 紅色格 = 該時間框架看跌

─────────────────────────────────────────────────────────
綠色格佔多數                              → 🟢 BUY
紅綠混合，沒有明顯多數                    → ⬛ WAIT
  ⚠️ 含：只有最後一格綠、其餘多數仍紅
    （短週期剛翻，長週期未跟上 = 轉換初期，等待確認）
紅色格佔多數                              → 🔴 SELL
```

---

#### WILLIAMS FRACTALS（威廉碎形）
> 在 K 線上下方標記近期高低點的小箭頭（△▽）。

**⚠️ 關鍵觀念：△▽ 標記的是「過去某根 K 棒」的高/低點價格水位，不是現在的 K 棒位置。**

```
判斷基準：看之後的 K 棒收盤價是否突破那個「過去」的價格水位
─────────────────────────────────────────────────────────
出現 △，且之後某根 K 棒收盤價「高於」△ 標記的最高點  → 🟢 BUY
  （K 棒不管紅綠，收盤在那個水位之上就算突破）
有 △▽ 但目前 K 棒尚未突破那個價格水位              → ⬛ WAIT
  （看到 △ 但當前 K 棒收在下方 = 尚未觸發，選 WAIT）
出現 ▽，且之後某根 K 棒收盤價「低於」▽ 標記的最低點  → 🔴 SELL
```

> ⚠️ 碎形訊號的有效性需搭配鱷魚確認，見下方組合指標。

---

#### WILLIAMS ALLIGATOR（威廉鱷魚）
> Bill Williams 三線趨勢系統。三條線 = 鱷魚的顎（Jaw）、牙（Teeth）、唇（Lips）。

| 顏色 | 線名 | 週期 |
|------|------|------|
| 🔵 藍線 | 顎 Jaw | 13 期，位移 8 |
| 🔴 紅線 | 牙 Teeth | 8 期，位移 5 |
| 🟢 綠線 | 唇 Lips | 5 期，位移 3 |

**判斷邏輯：**
```
三線糾纏           → 鱷魚睡覺，盤整，觀望
三線分開 + 價格在上  → 鱷魚張口向上，🟢 BUY
  由上到下：綠 > 紅 > 藍
三線分開 + 價格在下  → 鱷魚張口向下，🔴 SELL
  由上到下：藍 > 紅 > 綠
```

---

#### ↳ ALLIGATOR × FRACTAL（組合判斷）
> Bill Williams 原始系統核心規則：碎形訊號必須由鱷魚確認才有效。

**判斷邏輯：**
```
鱷魚張口向上 + 有K棒收盤「高於」上方 △ 碎形最高點  → 🟢 BUY（強力訊號）
鱷魚張口向下 + 有K棒收盤「低於」下方 ▽ 碎形最低點  → 🔴 SELL（強力訊號）
鱷魚睡覺（三線糾纏）                                 → ⬛ WAIT（碎形訊號無效，忽略）
鱷魚方向與碎形訊號相反                               → ⬛ WAIT（訊號矛盾，觀望）
```

---

#### PARABOLIC SAR（拋物線停損）
> 一排跟隨趨勢的小圓點，出現在 K 線上方或下方。

**判斷邏輯：**
```
SAR 點持續在 K 線下方    → 🟢 BUY（上升趨勢）
SAR 點剛翻到 K 線下方    → 🟢 BUY（趨勢轉換入場）
SAR 點持續在 K 線上方    → 🔴 SELL（下降趨勢）
SAR 點剛翻到 K 線上方    → 🔴 SELL（出場訊號）
```

---

### COL 2 — CHANNEL（通道系統）

#### BOLLINGER BANDS（布林通道）
> 以移動平均線為中軌，上下各加減 2 倍標準差為上下軌。

**判斷邏輯：**
```
觸碰/突破上軌
  + 帶寬擴大（通道張開）  → 🟢 BUY
  + 帶寬收窄（通道緊縮）  → ⬛ WAIT（注意假突破）
在中軌附近游走            → ⬛ WAIT
觸碰/跌破下軌
  + 帶寬擴大（通道張開）  → 🔴 SELL
  + 帶寬收窄（通道緊縮）  → ⬛ WAIT（可能反彈）
```

---

#### KELTNER CHANNEL（肯特納通道）
> 以 EMA 為中線，上下各加減 ATR 倍數，比布林通道更平滑。

**判斷邏輯：**
```
突破上軌且站穩  → 🟢 BUY
在通道內部游走  → ⬛ WAIT
跌破下軌且站穩  → 🔴 SELL
```

---

#### BB / KC SQUEEZE（布林 × 肯特納擠壓）
> 同時觀察兩個通道的寬窄關係，判斷市場是否處於蓄勢待發狀態。

**概念：**
```
BB 比 KC 窄（BB 收在 KC 裡面）  → Squeeze ON：能量積聚，等待方向
BB 比 KC 寬（BB 突出 KC 外側）  → Squeeze OFF：行情啟動
```

**判斷邏輯：**
```
BB 收在 KC 裡面                    → ⬛ WAIT（蓄勢待發）
BB 突出 KC 外 + K 線向上突破       → 🟢 BUY
BB 突出 KC 外 + K 線向下突破       → 🔴 SELL
```

---

#### MA CROSS（均線交叉）
> 專門標記短線均線穿越長線均線的交叉事件。

**判斷邏輯：**
```
金叉（短均從下穿上長均）  → 🟢 BUY（多頭轉換）
無交叉，均線平行          → ⬛ WAIT（延續趨勢）
死叉（短均從上穿下長均）  → 🔴 SELL（空頭轉換）
```

---

#### VOLATILITY STOP（波動停損）
> 類似 SAR，依波動率計算的動態停損線。

**判斷邏輯：**
```
綠色線在 K 線下方  → 🟢 BUY
紅色線在 K 線上方  → 🔴 SELL
```

---

### COL 3 — MOVING AVERAGE（均線系統）

#### MA 20 / 50（簡單移動平均線）
> MA20 反應較快（橙色），MA50 反應較慢，兩者排列判斷趨勢。

**判斷邏輯：**
```
K線 > MA20 > MA50（多頭排列）  → 🟢 BUY
均線糾纏或交叉混亂              → ⬛ WAIT
MA50 > MA20 > K線（空頭排列）  → 🔴 SELL
```

---

#### EMA 20 / 50（指數移動平均線）
> 圖上共兩條 EMA（青色系）：EMA20 較敏感、EMA50 較慢。
> 同一欄還有 MA 20/50（橙色），兩組線疊在一起，靠顏色分辨。

**判斷邏輯：**
```
K線 > EMA20 > EMA50（多頭排列）  → 🟢 BUY
兩條 EMA 糾纏或交叉混亂           → ⬛ WAIT
  ⚠️ 含只有部分順序正確的情況
    （例如 K線站上 EMA20，但 EMA20 仍在 EMA50 下方 = 尚未確認）
EMA50 > EMA20 > K線（空頭排列）  → 🔴 SELL
```

---

#### DONCHIAN CHANNELS（唐奇安通道）
> 上軌 = 近 N 期最高點，下軌 = 近 N 期最低點，通道突破代表創新高/低。

**⚠️ 純突破型指標：只看有沒有突破邊界，通道內部不管偏上偏下都是 WAIT。**

```
K 線突破上軌（創近期新高）          → 🟢 BUY
K 線在通道內部（含中線偏上或偏下）  → ⬛ WAIT（未突破邊界 = 無訊號）
K 線跌破下軌（創近期新低）          → 🔴 SELL
```

---

#### ↳ MA × EMA 共振（組合判斷）
> MA（慢）與 EMA（快）方向一致時，趨勢訊號更可靠。

**判斷邏輯：**
```
MA 和 EMA 都多頭排列  → 🟢 BUY（共振確認）
方向不一致            → ⬛ WAIT（趨勢轉換中）
MA 和 EMA 都空頭排列  → 🔴 SELL（共振確認）
```

---

### COL 4 — TREND / EXIT（趨勢結構 / 出場）

#### ZIG ZAG（折線指標）
> 連接重要高低點，形成 W 型（底部）或 M 型（頂部）的折線結構。

**判斷邏輯：**
```
高點遞升 + 低點遞升（每波都比上一波高）  → 🟢 BUY
高低點無規律                              → ⬛ WAIT
高點遞降 + 低點遞降（每波都比上一波低）  → 🔴 SELL
```

---

#### SUPERTREND（超級趨勢線）
> 跟隨趨勢的動態支撐/阻力線。

**⚠️ 重要：以 K 線位置為準，顏色是結果不是原因。**

```
K 線在線的上方（不管線是綠或紅）  → 🟢 BUY
K 線在線的下方（不管線是綠或紅）  → 🔴 SELL
```

> 若看到紅線但 K 線在線上方，這是趨勢剛轉換的訊號，選「K線在上方」= BUY。

---

#### LINEAR REGRESSION（線性迴歸）
> 穿越 K 線的趨勢基準直線，斜率反映趨勢方向。

**判斷邏輯：**
```
K線在線上方 + 斜率向上  → 🟢 BUY
K線在線附近 + 近乎水平  → ⬛ WAIT
K線在線下方 + 斜率向下  → 🔴 SELL
```

---

#### ↳ SAR × LINEAR REG（組合判斷）
> SAR 抓短線轉折，線性迴歸看整段趨勢斜率。兩者同向 = 短線與中期趨勢對齊。

**判斷邏輯：**
```
SAR 點在下方 + 迴歸線斜率向上  → 🟢 BUY（短中期趨勢一致）
兩者方向不一致（含迴歸線近乎水平）  → ⬛ WAIT（短線與趨勢矛盾）
SAR 點在上方 + 迴歸線斜率向下  → 🔴 SELL（短中期趨勢一致）
```

---

#### VWMA（量加權移動平均線）
> 納入成交量權重的移動平均線，比普通 MA 更能反映市場真實方向。

**判斷邏輯：**
```
K線在 VWMA 上方 + VWMA 向上  → 🟢 BUY（有量支撐）
K線在 VWMA 附近游走           → ⬛ WAIT
K線在 VWMA 下方 + VWMA 向下  → 🔴 SELL（有量下壓）
```

## Section B — PAGE II ─ Pane（`o/{symbol}.html`）

對應圖表：`4 組 × ?t= 指定的級別（預設 4H）`，共 **17 個核對項目**。

> 級別由網址參數決定：`o/btc.html?t=1d`、`o/btc.html?t=1h`、`o/btc.html`（= 4h）。
> 支援 `15m / 1h / 4h / 1d`，填錯會自動回退 4h 並在 console 提示。
> **核對時務必讓 `?t=` 與 Section A 的 TIMEFRAME 一致**，否則等於拿兩個不同週期的訊號在同一張表上計分。

**版面與其他頁不同：** 每一組是**一張圖**，不是一欄多張。主圖指標疊在價格走勢上，
另外三個指標各自成為下方獨立的副圖窗格（Pane）—— 這也是標題掛 `Pane` 的原因。

| 組別 | 主圖指標 | 副圖指標（Pane） |
|------|---------|-----------------|
| 第一組 · 趨勢面 | Supertrend | MACD · DMI/ADX · Aroon |
| 第二組 · 動能面 | Hull MA (HMA) | RSI · Stochastic RSI · ROC |
| 第三組 · 波動面 | Bollinger Bands | ATR · Choppiness Index · Historical Volatility |
| 第四組 · 量價面 | VWMA 20 | On Balance Volume · MFI · Chaikin Money Flow |

### 第一組 · 趨勢面

#### SUPERTREND（超級趨勢線）
> 同 Section A COL 1，以 K 線位置為準（不看顏色）。此處為第一組的主圖指標。

---

#### MACD（指數平滑異同移動平均）
> 觀察柱狀圖（Histogram）的位置與方向，判斷多空動能強弱。

**判斷邏輯：**
```
正值柱（零軸上方）且持續增高  → 🟢 BUY（多頭加速）
柱狀縮小或接近零軸            → ⬛ WAIT（動能減弱）
負值柱（零軸下方）且持續增高  → 🔴 SELL（空頭加速）
```

---

#### DMI / ADX（趨向指標）
> 三條線：+DI（多方力道）、−DI（空方力道）、ADX（趨勢強度，**不分方向**）。

**⚠️ ADX 是門檻，先看它夠不夠高，再看 DI 誰領先。ADX 太低時 DI 交叉多為假訊號。**

```
+DI 在 −DI 上方，且 ADX > 25  → 🟢 BUY（多方佔優且趨勢確立）
ADX 未站上 25（不論 DI 誰上）  → ⬛ WAIT（盤整無趨勢，別追勢）
−DI 在 +DI 上方，且 ADX > 25  → 🔴 SELL（空方佔優且趨勢確立）
```

---

#### AROON（阿隆指標）
> 兩條 0~100 的線。Up 高 = 近期常創新高；Down 高 = 近期常創新低；兩線交叉代表趨勢轉換。

**判斷邏輯：**
```
Up 接近 100 且明顯高於 Down    → 🟢 BUY（上升趨勢）
兩線都在中間帶（50 附近）交纏  → ⬛ WAIT（趨勢未成形）
Down 接近 100 且明顯高於 Up    → 🔴 SELL（下降趨勢）
```

---

#### ↳ SUPERTREND × MACD（組合判斷）
> 同一張圖上的主圖 + 副圖：Supertrend 看趨勢方向，MACD 看動能方向。

**判斷邏輯：**
```
K 線在超級趨勢線上方 + MACD 正值柱  → 🟢 BUY（趨勢 × 動能多頭共振）
兩者方向不一致                       → ⬛ WAIT（趨勢與動能矛盾）
K 線在超級趨勢線下方 + MACD 負值柱  → 🔴 SELL（趨勢 × 動能空頭共振）
```

---

### 第二組 · 動能面

#### HULL MA (HMA)（赫爾均線）
> 超低延遲快速均線，比 EMA 更早反映轉折與加速。看兩件事：K 線位置 + 線的斜率。

**判斷邏輯：**
```
K 線在 HMA 上方 + HMA 上揚  → 🟢 BUY（短多）
K 線貼著 HMA，或 HMA 走平   → ⬛ WAIT（短線方向未定）
K 線在 HMA 下方 + HMA 下彎  → 🔴 SELL（短空）
```

---

#### RSI（相對強弱指標）
> 0~100 的振盪器。50 是多空分界，> 70 超買、< 30 超賣。

**⚠️ 極端區（> 70 / < 30）不能只看數值，要再確認有沒有背離。**

```
RSI > 70（超買區）
  + 價創新高時 RSI 同步創高      → 🟢 BUY（強勢趨勢延續）
  + 價創新高但 RSI 未創高（頂背離）→ 🔴 SELL（動能衰竭，慎防反轉）
50 ~ 70（偏多但未超買）           → 🟢 BUY
45 ~ 55 附近游走                  → ⬛ WAIT（多空均衡）
30 ~ 50（偏空但未超賣）           → 🔴 SELL
RSI < 30（超賣區）
  + 價創新低時 RSI 同步創低      → 🔴 SELL（弱勢趨勢延續）
  + 價創新低但 RSI 未創低（底背離）→ 🟢 BUY（賣壓衰竭，潛在反彈）
```

---

#### STOCHASTIC RSI（隨機相對強弱）
> 比 RSI 更敏感的振盪器，0~100，> 80 超買、< 20 超賣。**重點看交叉發生在什麼高度。**

**判斷邏輯：**
```
低檔（< 20），%K 由下往上穿越 %D  → 🟢 BUY（低檔黃金交叉）
中間帶（20~80）兩線纏繞、無交叉   → ⬛ WAIT（訊號不明確）
高檔（> 80），%K 由上往下穿越 %D  → 🔴 SELL（高檔死亡交叉）
```

---

#### ROC（變動率）
> 量測價格變動的速度。穿越零軸 = 動能轉向；與價格背離 = 動能衰竭。

**判斷邏輯：**
```
零軸以上且持續走高  → 🟢 BUY（上漲動能增強）
在零軸附近來回穿越  → ⬛ WAIT（動能不足）
零軸以下且持續走低  → 🔴 SELL（下跌動能增強）
```

---

### 第三組 · 波動面

#### BOLLINGER BANDS（布林通道）
> 同 Section A COL 2。此處為第三組的主圖指標，並作為 Choppiness 的方向參考。

**判斷邏輯：**
```
觸碰/突破上軌 + 帶寬擴大  → 🟢 BUY
觸碰/突破上軌 + 帶寬收窄  → ⬛ WAIT（注意假突破）
在中軌附近游走            → ⬛ WAIT
觸碰/跌破下軌 + 帶寬擴大  → 🔴 SELL
觸碰/跌破下軌 + 帶寬收窄  → ⬛ WAIT（可能反彈）
```

---

#### AVG TRUE RANGE (ATR)（平均真實波幅）
> 衡量市場波動幅度，本身不判斷方向，配合趨勢判斷進場時機。

**判斷邏輯：**
```
ATR 擴大（波動增加）
  + K 線配合上漲  → 🟢 BUY（有力突破）
  + K 線配合下跌  → 🔴 SELL（有力跌破）
ATR 收縮（波動減少）  → ⬛ WAIT（蓄勢待發）
```

---

#### CHOPPINESS INDEX（波動指數）
> **⚠️ CI 只判斷「有沒有趨勢」，不判斷方向。** 這是最容易誤用的一個指標。

```
< 38.2（趨勢明顯）
  + K 線向上、貼近布林上軌  → 🟢 BUY（順勢做多）
  + K 線向下、貼近布林下軌  → 🔴 SELL（順勢做空）
38.2 ~ 61.8（中間區）        → ⬛ WAIT（趨勢強度不明）
> 61.8（盤整）               → ⬛ WAIT（別追勢）
```

> CI > 61.8 時，同一張表上所有趨勢型指標的訊號可靠度都會下降，應調降權重。

---

#### HISTORICAL VOLATILITY（歷史波動率）
> 只反映波動大小，不含方向。低檔常出現在大行情之前，高檔多見於行情末段。

**判斷邏輯：**
```
相對低檔且開始翻揚
  + K 線向上突破  → 🟢 BUY（行情啟動）
  + K 線向下突破  → 🔴 SELL（行情啟動）
  + 尚未明確突破  → ⬛ WAIT（等突破確認）
相對低檔且持續低迷  → ⬛ WAIT（波動壓縮，蓄勢待變）
相對高檔（已放大一段時間）→ ⬛ WAIT（常為行情末段，追價不利）
```

---

### 第四組 · 量價面

#### VWMA（量加權移動平均線）
> 同 Section A COL 4。此處為第四組的主圖指標。K 線在其上且線向上 → BUY；反之 → SELL。

---

#### ON BALANCE VOLUME（OBV 能量潮）
> 累積成交量趨勢線，方向應與 K 線一致；若不一致則為背離警告。

**判斷邏輯：**
```
OBV 與 K 線同步上升  → 🟢 BUY（量價齊揚）
OBV 與 K 線方向相反  → ⬛ WAIT（量價背離，注意反轉）
OBV 與 K 線同步下降  → 🔴 SELL（量價齊跌）
```

---

#### MFI（資金流量指標）
> 量加權版的 RSI，0~100。> 80 超買、< 20 超賣。與 RSI 的差別在於它把成交量算進去。

**判斷邏輯：**
```
50 以上且持續走高                    → 🟢 BUY（資金流入，買方主導）
在 50 附近游走                       → ⬛ WAIT（資金流向不明）
> 80 超買，且價創新高而 MFI 未同步   → 🔴 SELL（頂背離，資金轉弱）
50 以下且持續走低                    → 🔴 SELL（資金流出，賣方主導）
```

---

#### CHAIKIN MONEY FLOW（CMF 資金流向）
> 零軸上下的柱狀指標，反映資金流入或流出的方向與強度。

**判斷邏輯：**
```
正值（零軸以上）且持續上升  → 🟢 BUY（資金流入）
接近零軸或橫盤              → ⬛ WAIT
負值（零軸以下）且持續下降  → 🔴 SELL（資金流出）
```

```
一項都還沒核對                  → — NOT CHECKED（尚未開始，不是結論）
已核對項目中，BUY 佔比 ≥ 60%  → ▲ BUY（看漲，可考慮買入）

其餘情況                        → ◈ WAIT（方向不明，觀望）

分母只算已核對項目，隨選隨變，不需填滿 ─ 只跑 Section A 也會給方向。
覆蓋率（如 19/36）另行標示，數字太小時結論僅供參考。
```
