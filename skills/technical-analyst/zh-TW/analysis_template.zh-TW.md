## 0. 預測摘要（結論先行）

**這是原版沒有、新增的一節。** 讓結論一眼可讀，不必翻到第八節。

| 欄位 | 說明 |
|------|------|
| **方向** | Up ／ Down ／ Flat |
| **機率** | 領先情境的機率，並列出三者 |
| **最近收盤 C** | 價格 |
| **ATR(14)** | 數值，並註明是**從圖上讀到**還是**目視估計** |
| **平盤區** | C − 0.5 ATR 到 C + 0.5 ATR |
| **預期區間** | C ± 1 ATR |
| **失效價位** | 打破領先情境的價格 |
| **可讀性** | 幾項可讀 / 共幾項 |

**一句話結論**：領先結果 + 最主要的驅動因素。

## 7. 波動度與預期區間

**這是原版沒有、新增的一節。**

| 欄位 | 值 |
|------|-----|
| ATR(14) | 數值 —— 從圖上讀到／目視估計 |
| ATR 佔價格比 | % |
| 波動狀態 | 壓縮／正常／擴張 |
| 平盤區（C ± 0.5 ATR） | 下界 到 上界 |
| 預期區間（C ± 1 ATR） | 下界 到 上界 |
| Choppiness Index | 數值 → 趨勢（< 38.2）／不明確／盤整（> 61.8） |
| Historical Volatility | 數值、相對高低檔、是否翻揚 |
| 布林／肯特納 | 觸及哪條軌道，以及帶寬擴張或收縮 |

**以上沒有一項提供方向。** Choppiness 高於 61.8 時，會調降第 6 節**每一個**趨勢追蹤讀數的權重——若適用要明確寫出來。

### 備註
波動在壓縮還是擴張？圖表是否呈現應偏向 Flat 的區間特徵？

**證據**：一句話。

## 10. 情境分析

三個情境互斥且窮盡，機率加總 100%，以 5% 為級距。

### A：Up — XX%
次日收盤 > C + 0.5 ATR

- **支持證據**：類別 — 指標 — 讀數（逐條列出，必須具名）
- **預期價格區間**
- **失效價位**：通常是跌破最近支撐或最近一根 K 棒低點

### B：Down — XX%
次日收盤 < C − 0.5 ATR，欄位同上，失效價位通常是突破最近阻力或最近 K 棒高點。

### C：Flat / Range — XX%
次日收盤落在 C ± 0.5 ATR 內，失效價位是決定性地收在平盤區之外。

## 11. 總結

- **領先結果** — 一兩句話說明最高機率情境與其驅動因素
- **關注價位** — 上方觸發價、下方觸發價、領先判斷的失效價
- **風險考量** — 不可讀項目、缺席指標、有開收盤市場的跳空風險、圖上看不到的排程事件、矛盾訊號

## 12. 免責聲明

模板固定包含以下要點：

> 本預測純粹基於技術圖表資料，不考慮基本面、新聞或市場情緒。
>
> **單日方向接近隨機**，且由圖表上不存在的資訊主導。上述機率是粗略分級而非精確估計——40~55% 應讀作「真的不確定」，超過 70% 則視為單靠圖表判讀無法支撐。這是機率性評估，不是預言，也不是投資建議。
